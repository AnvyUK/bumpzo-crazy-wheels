# BUMPZO! — Crazy Wheels

Original mobile-friendly HTML5 physics car obstacle game.

## Play
Open `index.html` from any static web host. No server, package installation or paid SDK required.

## Controls
- Phone: on-screen steering, jump and mode-switch buttons
- Desktop: left/right arrows (or A/D), Space to jump, Shift to switch mode

## Current version
Playable prototype v0.1; 12 levels. Saves progress in the browser. No ads or analytics yet.

## Safety
This repository is exclusively for BUMPZO!. Do not modify the owner's other GitHub repositories, Vercel projects, Render services, domains, or databases.

## Deployment
Deploy this repository as a **new standalone Cloudflare Pages project**, using static asset hosting: production branch `main`, build command empty, root output directory `/`. No monthly paid plan is required within Cloudflare's free limits. Any commercial game portal integration requires platform review and its SDK requirements.
